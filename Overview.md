# Overview

This file serves as a brief documentation of the library as well as references to papers where mathematical concepts are covered.

## Modules

### [base.py](./src/seaweed_algebra/base.py)

This is the [abstract base class](https://docs.python.org/3/library/abc.html) for the [seaweed](#seaweedpy) and [meander](#meanderpy) modules.

This module provides the basic underlying methods and variables used by all of its children (seaweed & meander).

Most notably, it holds the top & bottom "blocks" that denote a seaweed algebra.

### [seaweed.py](./src/seaweed_algebra/seaweed.py)

Presently, this module serves just as a way to pass the [base](#basepy) data to [seaweed_plot](#seaweed_plotpy) for visualization purposes along with a few private utility calculations.

### [meander.py](./src/seaweed_algebra/meander.py)

This module provides various calculations that are possible using meanders:
- `signature()`
    - As shown in  Lemma 1 [1], calculate the unique sequence of moves (Bl, R, P, F, C(c)) which reduce the meander to the empty meander.
- `homotopy()`
    - Get the list of ***component deletion*** steps in the order they occur in the meander's signature. This list can be used to create the ***homotopy type*** as defined in Lemma 1 [1].
- `component()`
    - As sown in Definition 2 [1], create the ***component meander*** using the ***winding-up*** process from the meander's signature.

Additionally, there are private functions which allow for the capabilities listed above:
- `_wind_down()`
    - Uses the steps outlined in Lemma 1 [1] to ***wind-down*** the meander until it is the empty meander. The relevant moves are implemented in: `_block_elimination()`, `_rotation_contraction()`, `_pure_contraction()`, `_flip()`, and `_component_deletion()`.
- `_wind_up()`
    - While not explicitly defined mathematically in [1], it does precisely the inverse of `_wind_down()` by starting with the empty meander, and reversing the moves of a provided signature using the inverse moves defined in: `_inv_block_elimination()`, `_inv_rotation_contraction()`, `_inv_pure_contraction()`, `_inv_flip()`, and `_inv_component_deletion()`.

### [latex_utils.py](./src/seaweed_algebra/latex_utils.py)

This module provides a utility function `export_as_pgf()` to convert Matplotlib plots (namely, those generated by [meander_plot](#meander_plotpy) and [seaweed_plot](#seaweed_plotpy)) to `.pgf` files, which are vector graphics files that can be used in LaTeX

The `export_as_pgf()` function takes the following arguments:
- Required arguments
    - `plot_mpl` This is a [`Callable`](https://typing.python.org/en/latest/spec/callables.html) which when called should prepare a Matplotlib figure. See [`partial`](https://www.geeksforgeeks.org/python/partial-functions-python/) for information on how to create a `Callable`.
    - `filename` The relative path and filename that the plot will be exported to. If `filename` does not end with `.pgf` it will be appended for you.
- Optional arguments
    - `texsystem` - The TeX system the pgf file should be compatible with. Defaults to `pdflatex`.

### [_visual_util.py](./src/seaweed_algebra/visual/_visual_util.py)

This is an internal module which provides some utility functions for the visualization modules: [seaweed_plot](#seaweed_plotpy) and [meander_plot](#meander_plotpy).

The module provides the following functions:
- `_get_edges()`
    - This converts an array of block sizes into a list of connected vertices along the meander / diagonal of the matrix.
- `generate_component_color_map()`
    - This takes in the base block size data and generates a color map representing which index belongs to which color using the following steps:
        1. Use the aforementioned `_get_edges()` function to generate a graph representing how the indices are connected to each other.
        2. Use a depth-first search algorithm to extract disjoint paths from the graph.
        3. Sort the collected paths by the smallest index they contain.
        4. Iterate through the collected paths, check if the next path is nested within the current path, if it is, group them together in a single cycle (since they're part of the same ***component deletion*** step.).
        5. Iterate through the selected cycles, giving them each a unique color.

### [seaweed_plot.py](./src/seaweed_algebra/visual/seaweed_plot.py)

This module is responsible for plotting a seaweed matrix using Matplotlib.

The `plot_seaweed()` function takes in the following arguments:
- Required arguments
    - `seaweed` - This is the `Seaweed` object to be plotted.
- Optional arguments
    - `ax` - This is the Matplotlib `Axes` object the seaweed will be plotted on. If not provided a figure is created for you. Defaults to `None`.
    - `size` - If `ax` is not provided, the created figure will be (`size` x `size`). Defaults to `5`.
    - `nonzero_element` - Controls if the non-zero element is plotted as a dot or an asterisk. `"*"` for asterisk, `"."` for dot. Defaults to `"*"`.
    - `draw_diagonal` - Controls whether the main diagonal is plotted. Defaults to `True`.
    - `draw_mender` - Controls whether The meander is overlaid inside the seaweed plot. Defaults to `False`.
    - `color_cycles` - If `draw_meander` is `True`, controls whether or not the meander overlay is colored or not. Defaults to `False`.

### [meander_plot.py](./src/seaweed_algebra/visual/meander_plot.py)

This module is responsible for plotting a meander using Matplotlib.

The `plot_meander()` function takes in the following arguments:
- Required arguments
    - `meander` - This is the `Meander` object to be plotted.
- Optional arguments
    - `ax` - This is the Matplotlib `Axes` object the meander will be plotted on. If not provided a figure is created for you. Defaults to `None`.
    - `arc_scale` - Decimal scaling factor for the arc heights. Defaults to `0.7`.
    - `color_cycles` - Controls whether or not the cycles are colored. Defaults to `False`.
    - `show_indices` - Controls whether or not the nodes should be circles labeled with their index or not. Defaults to `False`.
    - `node_size` - If `show_indices` is `True`, controls the size of the node circle size. Defaults to `14`.
    - `font_size` - If `show_indices` is `True`, controls the size of the node index labels. Defaults to `8`.
