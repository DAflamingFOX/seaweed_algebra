## Colab Setup

When you initially open Google Colabs, it may not have the seaweed-algebra library installed yet. If any of the code is not working try the following:

1. Wait for it to show that it is connected in the upper right corner
2. Click on `Terminal` in the lower left.
3. In the terminal window that opens up copy and paste in the following, then press enter. (see the [installation instructions](https://github.com/DAflamingFOX/seaweed_algebra/blob/main/README.md#Installation) for more info.)
    - `pip install seaweed-algebra`
4. The last line should say "Successfully installed seaweed-algebra-x.x.x" and the code should now work!
